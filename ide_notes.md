## VS Code — 3 удобные вещи для Git

- Визуальный diff изменений по каждому файлу
- Staging отдельных строк/блоков кода (не всего файла целиком)
- Удобнее делать коммиты и пуши — не нужно набирать команды, всё по кнопкам

## Терминал — 1 удобная вещь

- Интерактивный rebase и reflog — сложные операции с историей коммитов
